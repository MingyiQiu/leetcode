# 0707. Design Linked List

🔗 [LeetCode](https://leetcode.com/problems/design-linked-list/)

## Approach

Use a **Dummy Head + Size Tracking + Traversal** approach to implement a custom singly linked list.

- Create a dummy node to simplify edge cases (especially head insertion/deletion).
- Maintain a `size` variable to track the current length of the linked list.
- All operations are based on index traversal from the dummy node.

### Core Ideas

- **get(index)**  
  Traverse from dummy node to `index + 1` position and return node value.

- **addAtHead(val)**  
  Equivalent to inserting at index `0`.

- **addAtTail(val)**  
  Equivalent to inserting at index `size`.

- **addAtIndex(index, val)**  
  Traverse to `index`, insert a new node by adjusting pointers.

- **deleteAtIndex(index)**  
  Traverse to `index`, skip the target node by updating `next` pointer.

Using a dummy node avoids special handling for head operations, making all insert/delete logic uniform.

## Complexity

- Time Complexity: **O(n)** for get / add / delete operations
- Space Complexity: **O(1)** (excluding the linked list itself)

## Code

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class MyLinkedList:
    def __init__(self):
        self.dummy = ListNode()
        self.size = 0

    def get(self, index: int) -> int:
        if 0 <= index < self.size:
            curr = self.dummy
            for _ in range(index + 1):
                curr = curr.next
            return curr.val
        return -1

    def addAtHead(self, val: int) -> None:
        self.addAtIndex(0, val)

    def addAtTail(self, val: int) -> None:
        self.addAtIndex(self.size, val)

    def addAtIndex(self, index: int, val: int) -> None:
        if 0 <= index <= self.size:
            curr = self.dummy
            for _ in range(index):
                curr = curr.next
            curr.next = ListNode(val, curr.next)
            self.size += 1

    def deleteAtIndex(self, index: int) -> None:
        if 0 <= index < self.size:
            curr = self.dummy
            for _ in range(index):
                curr = curr.next
            curr.next = curr.next.next
            self.size -= 1
```
