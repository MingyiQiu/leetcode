# 0024. Swap Nodes in Pairs

🔗 [LeetCode](https://leetcode.com/problems/swap-nodes-in-pairs/)

## Approach

Use a **Dummy Head + Pointer Manipulation** approach to swap every two adjacent nodes in the linked list.

- Create a dummy node pointing to `head` to simplify edge cases.
- Use a pointer `curr` starting from `dummy`.
- While there are at least two nodes ahead (`curr.next` and `curr.next.next`):
  - Identify the next pair to swap.
  - Save the node after the pair as `nextPair`.
  - Let:
    - `first = curr.next`
    - `second = curr.next.next`
  - Perform the swap:
    - `curr.next` points to `second`
    - `second.next` points to `first`
    - `first.next` points to `nextPair`
  - Move `curr` forward to `first` (now the second node in the swapped pair)

This ensures nodes are swapped in-place without modifying values, only pointers.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        curr = dummy

        while curr.next and curr.next.next:
            nextPair = curr.next.next.next

            temp = curr.next
            curr.next = curr.next.next
            curr.next.next = temp
            temp.next = nextPair

            curr = temp

        return dummy.next
```
