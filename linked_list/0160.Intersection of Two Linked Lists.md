# 0160. Intersection of Two Linked Lists

🔗 [LeetCode](https://leetcode.com/problems/intersection-of-two-linked-lists/)

## Approach

Use a **Length Difference Alignment** approach to find the intersection node of two linked lists.

- Traverse both linked lists to calculate their lengths `lenA` and `lenB`.
- Align the starting point of the longer list:
  - If `lenA > lenB`, swap the two lists so that `headA` is always the shorter one.
- Move pointer `currB` forward by `lenB - lenA` steps so both pointers are aligned.
- Traverse both lists simultaneously:
  - If `currA == currB`, an intersection is found and return the node.
  - Otherwise, move both pointers forward.
- If no intersection is found, return `None`.

This ensures both pointers traverse equal remaining distance, making comparison straightforward.

## Complexity

- Time Complexity: **O(n + m)**
- Space Complexity: **O(1)**

## Code

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> ListNode:
        currA, currB = headA, headB
        lenA, lenB = 0, 0

        while currA:
            currA = currA.next
            lenA += 1

        while currB:
            currB = currB.next
            lenB += 1

        if lenA > lenB:
            headA, headB = headB, headA
            lenA, lenB = lenB, lenA

        currA, currB = headA, headB

        for _ in range(lenB - lenA):
            currB = currB.next

        while currB:
            if currA == currB:
                return currA
            currB = currB.next
            currA = currA.next

        return None
```
