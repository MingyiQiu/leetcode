# 0141. Linked List Cycle

🔗 [LeetCode](https://leetcode.com/problems/linked-list-cycle/)

## Approach

Use the **Floyd's Cycle Detection (Two Pointers)** approach to determine whether the linked list contains a cycle.

- Initialize two pointers:
  - `slow` moves one step at a time.
  - `fast` moves two steps at a time.
- Traverse the list while both `fast` and `fast.next` exist.
- Move `slow` forward by one node and `fast` forward by two nodes.
- If `slow` and `fast` meet at any point, a cycle exists, so return `True`.
- If `fast` reaches the end of the list, there is no cycle, so return `False`.

This approach works because if a cycle exists, the faster pointer will eventually catch up to the slower pointer inside the cycle.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow, fast = head, head

        while fast and fast.next:
            fast = fast.next.next
            slow = slow.next

            if fast == slow:
                return True

        return False
```
