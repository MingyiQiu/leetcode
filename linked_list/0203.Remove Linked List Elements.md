# 0203. Remove Linked List Elements

🔗 [LeetCode](https://leetcode.com/problems/remove-linked-list-elements/)

## Approach

Use a **Dummy Head + Traversal** approach to simplify node deletion, especially when the head node itself needs to be removed.

- Create a dummy node whose `next` points to `head`.
- Initialize a pointer `curr` at the dummy node.
- Traverse the linked list while `curr.next` exists.
- If `curr.next.val` is not equal to `val`, move `curr` forward.
- Otherwise, remove the target node by updating `curr.next` to `curr.next.next`.
- Return `dummy.next` as the new head of the linked list.

Using a dummy node avoids handling the head node as a special case and makes the deletion logic consistent for all nodes.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def removeElements(self, head: Optional[ListNode], val: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        curr = dummy

        while curr.next:
            if curr.next.val != val:
                curr = curr.next
            else:
                curr.next = curr.next.next

        return dummy.next
```
