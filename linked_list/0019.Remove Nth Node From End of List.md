# 0019. Remove Nth Node From End of List

🔗 [LeetCode](https://leetcode.com/problems/remove-nth-node-from-end-of-list/)

## Approach

Use a **Two Pointers (Fast & Slow) + Dummy Node** technique to remove the nth node from the end in one pass.

- Create a dummy node pointing to `head` to handle edge cases (like removing the first node).
- Initialize two pointers `slow` and `fast` at the dummy node.
- Move `fast` forward by `n` steps so that the gap between `slow` and `fast` is `n`.
- Move both pointers forward together until `fast.next` becomes `None`.
  - At this point, `slow.next` is the node to be removed.
- Skip the target node by setting `slow.next = slow.next.next`.
- Return `dummy.next` as the new head.

This method ensures a single traversal with clean handling of edge cases.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        slow, fast = dummy, dummy

        for _ in range(n):
            fast = fast.next

        while fast.next:
            fast = fast.next
            slow = slow.next

        slow.next = slow.next.next
        return dummy.next
```
