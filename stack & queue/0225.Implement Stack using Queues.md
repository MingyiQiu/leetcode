# 0225. Implement Stack using Queues

🔗 [LeetCode](https://leetcode.com/problems/implement-stack-using-queues/)

## Approach

Use a **Queue** to simulate the behavior of a stack.

- Initialize a queue using `deque`.
- For `push`, directly add the new element to the back of the queue.
- For `pop`, rotate the queue:
  - Move the first `n-1` elements from the front to the back.
  - The remaining front element is the stack top, so remove and return it.
- For `top`, call `pop()` to get the top element, then add it back to the queue to keep the stack unchanged.
- For `empty`, check whether the queue is empty.

By rotating the queue before removing elements, the last inserted element behaves like the top of a stack.

## Complexity

- Time Complexity:
  - `push`: **O(1)**
  - `pop`: **O(n)**
  - `top`: **O(n)**
  - `empty`: **O(1)**
- Space Complexity: **O(n)**

## Code

```python
from collections import deque

class MyStack:

    def __init__(self):
        self.queue = deque()

    def push(self, x: int) -> None:
        self.queue.append(x)

    def pop(self) -> int:
        for _ in range(len(self.queue) - 1):
            self.queue.append(self.queue.popleft())

        return self.queue.popleft()

    def top(self) -> int:
        top_value = self.pop()
        self.queue.append(top_value)

        return top_value

    def empty(self) -> bool:
        return not self.queue
```
