# 0232. Implement Queue using Stacks

🔗 [LeetCode](https://leetcode.com/problems/implement-queue-using-stacks/)

## Approach

Use **Two Stacks** to simulate the behavior of a queue.

- Use `inputStack` to store newly pushed elements.
- Use `outputStack` to provide queue operations.
- For `push`, simply append the element to `inputStack`.
- For `pop`:
  - If `outputStack` is empty, move all elements from `inputStack` to `outputStack`.
  - Pop and return the top element from `outputStack`.
- For `peek`:
  - Reuse the `pop` operation to get the front element.
  - Push the element back onto `outputStack`.
- For `empty`, return `True` only if both stacks are empty.

Moving elements only when `outputStack` is empty ensures that each element is transferred at most once, giving an amortized **O(1)** time complexity for queue operations.

## Complexity

- Time Complexity:
  - `push`: **O(1)**
  - `pop`: **O(1)** amortized
  - `peek`: **O(1)** amortized
  - `empty`: **O(1)**
- Space Complexity: **O(n)**

## Code

```python
class MyQueue:

    def __init__(self):
        self.inputStack = []
        self.outputStack = []

    def push(self, x: int) -> None:
        self.inputStack.append(x)

    def pop(self) -> int:
        if not self.outputStack:
            while self.inputStack:
                self.outputStack.append(self.inputStack.pop())

        return self.outputStack.pop()

    def peek(self) -> int:
        front = self.pop()
        self.outputStack.append(front)
        return front

    def empty(self) -> bool:
        return not self.inputStack and not self.outputStack
```
