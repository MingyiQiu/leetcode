# 1047. Remove All Adjacent Duplicates In String

🔗 [LeetCode](https://leetcode.com/problems/remove-all-adjacent-duplicates-in-string/)

## Approach

Use a **Stack** approach to remove adjacent duplicate characters.

- Initialize an empty stack.
- Traverse each character in the string.
- If the stack is not empty and the top element is the same as the current character, pop the top element.
- Otherwise, push the current character onto the stack.
- After processing all characters, join the characters in the stack to form the final string.

The stack keeps track of the characters that remain after removing adjacent duplicates, allowing each character to be processed only once.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
class Solution:
    def removeDuplicates(self, s: str) -> str:
        stack = []

        for char in s:
            if stack and stack[-1] == char:
                stack.pop()
            else:
                stack.append(char)

        return "".join(stack)
```
