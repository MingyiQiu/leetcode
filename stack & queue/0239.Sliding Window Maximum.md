# 0239. Sliding Window Maximum

🔗 [LeetCode](https://leetcode.com/problems/sliding-window-maximum/)

## Approach

Use a **Monotonic Queue** to keep track of the maximum value in the current sliding window.

- Maintain a decreasing queue where the largest element is always at the front.
- For each new element:
  - Remove all smaller elements from the back of the queue.
  - Push the current element into the queue.
- After filling the first window, record the maximum value from the front of the queue.
- As the window slides:
  - Add the new element to the queue.
  - Remove the outgoing element if it is equal to the front of the queue.
  - Record the current maximum from the front of the queue.
- Continue until all windows have been processed.

Since each element is added and removed at most once, the algorithm runs in linear time.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(k)**

## Code

```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        result = []
        self.mono_queue = deque()

        for i in range(k):
            self.push(nums[i])
        result.append(self.max_value())

        for i in range(k, len(nums)):
            self.push(nums[i])
            self.pop(nums[i - k])
            result.append(self.max_value())

        return result

    def max_value(self):
        return self.mono_queue[0]

    def push(self, val):
        while self.mono_queue and self.mono_queue[-1] < val:
            self.mono_queue.pop()
        self.mono_queue.append(val)

    def pop(self, val):
        if self.mono_queue and self.mono_queue[0] == val:
            self.mono_queue.popleft()
```
