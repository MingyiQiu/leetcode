# 0150. Evaluate Reverse Polish Notation

🔗 [LeetCode](https://leetcode.com/problems/evaluate-reverse-polish-notation/)

## Approach

Use a **Stack** to evaluate the Reverse Polish Notation expression.

- Create an empty stack to store operands.
- Traverse each token in the input list.
- If the token is a number, push it onto the stack.
- If the token is an operator:
  - Pop the top two operands from the stack.
  - The first popped value is the **right** operand, and the second is the **left** operand.
  - Perform the corresponding operation.
  - Push the result back onto the stack.
- After processing all tokens, the remaining value in the stack is the final result.

Using a stack naturally follows the evaluation order of Reverse Polish Notation and processes each token only once.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        stack = []
        operators = "+-*/"

        for token in tokens:
            if token in operators:
                right = stack.pop()
                left = stack.pop()

                if token == "+":
                    stack.append(left + right)
                elif token == "-":
                    stack.append(left - right)
                elif token == "*":
                    stack.append(left * right)
                else:
                    stack.append(int(left / right))
            else:
                stack.append(int(token))

        return stack[0]
```
