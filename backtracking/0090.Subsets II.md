# 0090. Subsets II

🔗 [LeetCode](https://leetcode.com/problems/subsets-ii/)

## Approach

Use a **Backtracking** approach to generate all possible subsets while avoiding duplicates.

- Sort `nums` to group duplicate elements together.
- Initialize an empty `path` to store the current subset and `res` to store all subsets.
- Perform backtracking starting from index `0`.
- Add a copy of `path` to `res` at each recursive call.
- Iterate through the remaining elements:
  - Skip duplicate elements at the same recursion level if `i > start_index` and `nums[i] == nums[i - 1]`.
  - Add the current element to `path`.
  - Recursively explore the next elements starting from `i + 1`.
  - Backtrack by removing the last element from `path`.

Sorting and skipping duplicates at the same recursion level ensures that each unique subset is generated only once.

## Complexity

- Time Complexity: **O(n × 2^n)**
- Space Complexity: **O(n)**, excluding the space used to store the result.

## Code

```python
class Solution:
    def subsetsWithDup(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        path = []
        res = []
        self.backtrack(nums, 0, path, res)
        return res

    def backtrack(self, nums, start_index, path, res):
        res.append(path[:])

        for i in range(start_index, len(nums)):
            if i > start_index and nums[i] == nums[i - 1]:
                continue

            path.append(nums[i])
            self.backtrack(nums, i + 1, path, res)
            path.pop()
```
