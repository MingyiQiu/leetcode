# 0077. Combinations

🔗 [LeetCode](https://leetcode.com/problems/combinations/)

## Approach

Use a **Backtracking** approach to generate all combinations of `k` numbers from `1` to `n`.

- Initialize an empty `path` to store the current combination and `res` to store all valid combinations.
- Start backtracking from index `1`.
- If `len(path) == k`, append a copy of `path` to `res` and return.
- Iterate from `start_index` to `n - (k - len(path)) + 1`:
  - Add the current number `i` to `path`.
  - Recursively backtrack starting from `i + 1` to avoid duplicate combinations.
  - Remove the last number from `path` to backtrack and explore other possibilities.

The loop boundary uses **pruning** to avoid exploring numbers when there are not enough remaining elements to complete the combination.

## Complexity

- Time Complexity: **O(k × C(n, k))**
- Space Complexity: **O(k)**, excluding the space used to store the results.

## Code

```python
class Solution:
    def combine(self, n: int, k: int) -> List[List[int]]:
        path = []
        res = []
        self.backtrack(n, k, 1, path, res)
        return res

    def backtrack(self, n, k, start_index, path, res):
        if len(path) == k:
            res.append(path[:])
            return

        for i in range(start_index, n - (k - len(path)) + 2):
            path.append(i)
            self.backtrack(n, k, i + 1, path, res)
            path.pop()
```
