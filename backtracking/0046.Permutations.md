# 0046. Permutations

🔗 [LeetCode](https://leetcode.com/problems/permutations/)

## Approach

Use a **Backtracking + Used Array** approach to generate all possible permutations.

- Initialize an empty `path` to store the current permutation.
- Initialize `res` to store all valid permutations.
- Create a `used` array to track which elements have been selected.
- If `len(path) == len(nums)`, a complete permutation is found:
  - Append a copy of `path` to `res`.
  - Return to the previous recursive call.
- Iterate through all elements in `nums`:
  - Skip the element if it has already been used.
  - Mark the element as used and add it to `path`.
  - Recursively explore the next position.
  - Backtrack by removing the last element from `path` and resetting `used[i]` to `False`.
- Return `res` containing all possible permutations.

The `used` array ensures that each element is selected only once in each permutation, while backtracking allows trying different combinations.

## Complexity

- Time Complexity: **O(n × n!)**
- Space Complexity: **O(n)** auxiliary space, excluding the output. The recursion stack, `path`, and `used` array each require O(n) space.

## Code

```python
class Solution:
    def permute(self, nums: list[int]) -> list[list[int]]:
        path = []
        res = []
        used = [False] * len(nums)

        self.backtracking(nums, path, res, used)
        return res

    def backtracking(self, nums, path, res, used):
        if len(path) == len(nums):
            res.append(path[:])
            return

        for i in range(len(nums)):
            if used[i]:
                continue

            used[i] = True
            path.append(nums[i])

            self.backtracking(nums, path, res, used)

            path.pop()
            used[i] = False
```
