# 0093. Restore IP Addresses

🔗 [LeetCode](https://leetcode.com/problems/restore-ip-addresses/)

## Approach

Use a **Backtracking** approach to generate all possible valid IP addresses.

- Initialize an empty `path` to store the current IP segments and `res` to store valid IP addresses.
- Recursively explore possible segments starting from `start_index`.
- If `path` contains 4 segments:
  - If `start_index` reaches the end of the string, join the segments with `.` and add the result to `res`.
  - Otherwise, return because a valid IP address must contain exactly 4 segments.
- Iterate through possible segments:
  - Convert the current substring into an integer and check if it is greater than 255. If so, stop exploring longer segments.
  - Check if the segment has a leading zero. If so, only `"0"` is valid.
  - Add the valid segment to `path` and recursively explore the remaining string.
  - Backtrack by removing the last segment from `path`.

Backtracking explores all possible combinations while pruning invalid segments early.

## Complexity

- Time Complexity: **O(3^4)**, since an IP address contains exactly 4 segments, and each segment can contain at most 3 digits.
- Space Complexity: **O(4)** for the recursion stack and the current path, excluding the output.

## Code

```python
class Solution:
    def restoreIpAddresses(self, s: str) -> list[str]:
        path = []
        res = []
        self.backtracking(s, 0, path, res)
        return res

    def backtracking(self, s, start_index, path, res):
        if len(path) == 4:
            if start_index == len(s):
                res.append(".".join(path[:]))
            return

        for i in range(start_index, len(s)):
            segment = s[start_index : i + 1]
            if int(segment) > 255:
                break
            elif segment[0] == '0' and segment != "0":
                break

            path.append(segment)
            self.backtracking(s, i + 1, path, res)
            path.pop()
```
