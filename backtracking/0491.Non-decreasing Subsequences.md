# 0491. Non-decreasing Subsequences

🔗 [LeetCode](https://leetcode.com/problems/non-decreasing-subsequences/)

## Approach

Use a **Backtracking + Set** approach to find all non-decreasing subsequences with at least two elements.

- Initialize an empty `path` to store the current subsequence and `res` to store all valid subsequences.
- Start backtracking from index `0`.
- If `len(path) >= 2`, add a copy of `path` to `res`.
- Use a local `used` set at each recursion level to avoid duplicate elements at the same level.
- Iterate through the remaining elements starting from `start_index`:
  - Skip the current element if it is smaller than the last element in `path`.
  - Skip the current element if it has already been used at the current recursion level.
  - Add the current element to `used` and `path`.
  - Recursively explore the next index.
  - Backtrack by removing the last element from `path`.
- Return `res` containing all unique non-decreasing subsequences.

Using a local set at each recursion level avoids duplicate subsequences while allowing the same element to be used at different recursion levels.

## Complexity

- Time Complexity: **O(n × 2^n)**, where `n` is the length of `nums`.
- Space Complexity: **O(n)** for the recursion stack and current path, excluding the output.

## Code

```python
class Solution:
    def findSubsequences(self, nums: list[int]) -> list[list[int]]:
        path = []
        res = []
        self.backtracking(nums, path, res, 0)
        return res

    def backtracking(self, nums, path, res, start_index):
        if len(path) >= 2:
            res.append(path[:])

        used = set()
        for i in range(start_index, len(nums)):
            if path and path[-1] > nums[i]:
                continue
            if nums[i] in used:
                continue

            used.add(nums[i])
            path.append(nums[i])
            self.backtracking(nums, path, res, i + 1)
            path.pop()
```
