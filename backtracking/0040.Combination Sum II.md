# 0040. Combination Sum II

🔗 [LeetCode](https://leetcode.com/problems/combination-sum-ii/)

## Approach

Use a **Backtracking + Sorting** approach to find all unique combinations whose sum equals the target.

- Sort `candidates` to make duplicate handling and pruning easier.
- Initialize an empty `path` to store the current combination and `res` to store all valid combinations.
- Use backtracking to explore possible combinations:
  - If `current_sum == target`, append a copy of `path` to `res` and return.
  - Iterate through the candidates starting from `start_index`.
  - If `current_sum + candidates[i] > target`, break because the remaining candidates are also too large.
  - Skip duplicate candidates at the same recursion level to avoid duplicate combinations.
  - Add the current candidate to `path` and recursively search from `i + 1` to ensure each candidate is used at most once.
  - Backtrack by removing the last candidate from `path`.

Sorting allows early pruning, while skipping duplicates at the same recursion level ensures that each combination appears only once.

## Complexity

- Time Complexity: **O(2^n)**, where `n` is the number of candidates, excluding the cost of copying valid combinations.
- Space Complexity: **O(n)** for the recursion stack and the current path, excluding the result list.

## Code

```python
class Solution:
    def combinationSum2(self, candidates: list[int], target: int) -> list[list[int]]:
        candidates.sort()
        path = []
        res = []
        self.backtracking(candidates, target, 0, 0, path, res)
        return res

    def backtracking(self, candidates, target, start_index, current_sum, path, res):
        if current_sum == target:
            res.append(path[:])
            return

        for i in range(start_index, len(candidates)):
            if current_sum + candidates[i] > target:
                break
            if i > start_index and candidates[i] == candidates[i - 1]:
                continue

            path.append(candidates[i])
            self.backtracking(candidates, target, i + 1, current_sum + candidates[i], path, res)
            path.pop()
```
