# 0039. Combination Sum

🔗 [LeetCode](https://leetcode.com/problems/combination-sum/)

## Approach

Use a **Backtracking** approach to explore all possible combinations that sum up to the target.

- Sort `candidates` to enable early pruning.
- Initialize an empty `path` to track the current combination and `res` to store valid combinations.
- Use backtracking to explore candidates:
  - If `current_sum == target`, add a copy of `path` to `res` and return.
  - Iterate through candidates starting from `start_index`.
  - If `current_sum + candidates[i] > target`, break the loop because the candidates are sorted.
  - Add the current candidate to `path` and recursively explore further.
  - Pass `i` as the next `start_index` to allow reusing the same candidate.
  - Backtrack by removing the last candidate from `path`.
- Return `res` containing all valid combinations.

Sorting allows early pruning, while using `i` instead of `i + 1` allows each candidate to be chosen multiple times.

## Complexity

- Time Complexity: **O(n^(target/min(candidates)))** (upper-bound estimate, excluding the cost of copying valid combinations).
- Space Complexity: **O(target/min(candidates))** for the recursion stack and current path, excluding the output.

## Code

```python
class Solution:
    def combinationSum(self, candidates: list[int], target: int) -> list[list[int]]:
        candidates.sort()
        path = []
        res = []
        self.backtracking(candidates, target, 0, 0, path, res)
        return res

    def backtracking(self, candidates, target, start_index, current_sum, path, res):
        if current_sum == target:
            res.append(path[:])
            return

        for i in range(start_index, len(candidates)):
            if candidates[i] + current_sum > target:
                break

            path.append(candidates[i])
            self.backtracking(candidates, target, i, current_sum + candidates[i], path, res)
            path.pop()
```
