# 0216. Combination Sum III

🔗 [LeetCode](https://leetcode.com/problems/combination-sum-iii/)

## Approach

Use a **Backtracking** approach to find all combinations of `k` numbers from 1 to 9 that sum up to `n`.

- Initialize an empty `path` to store the current combination and `result` to store all valid combinations.
- Start backtracking from `1` with an initial sum of `0`.
- If the length of `path` reaches `k`:
  - If `total == n`, append a copy of `path` to `result`.
  - Return to explore other combinations.
- Iterate through the remaining numbers starting from `start_index`:
  - If `total + i > n`, stop exploring further numbers since the sum can only increase.
  - Add `i` to `path` and recursively search for the next number, updating `total`.
  - Backtrack by removing the last number from `path`.
- Use `11 - (k - len(path))` as the upper bound to ensure enough numbers remain to complete the combination.

The `start_index` ensures that each number is used only once and combinations are generated without duplicates. The pruning conditions help reduce unnecessary exploration.

## Complexity

- Time Complexity: **O(C(9, k) \* k)**, where `C(9, k)` is the number of possible combinations and `k` is the length of each combination.
- Space Complexity: **O(k)** for the recursion stack and the current path, excluding the output.

## Code

```python
class Solution:
    def combinationSum3(self, k: int, n: int) -> List[List[int]]:
        path = []
        result = []
        self.backtrack(k, n, 1, path, result, 0)
        return result

    def backtrack(self, k, n, start_index, path, result, total):
        if len(path) == k:
            if total == n:
                result.append(path[:])
            return

        for i in range(start_index, 11 - (k - len(path))):
            if total + i > n:
                break

            path.append(i)
            self.backtrack(k, n, i + 1, path, result, total + i)
            path.pop()
```
