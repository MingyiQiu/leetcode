# 0017. Letter Combinations of a Phone Number

🔗 [LeetCode](https://leetcode.com/problems/letter-combinations-of-a-phone-number/)

## Approach

Use a **Backtracking** approach to generate all possible letter combinations.

- Create a phone map to map each digit to its corresponding letters.
- Initialize an empty `path` to track the current combination and an empty `res` to store all valid combinations.
- Start backtracking from index `0`:
  - If the length of `path` equals the length of `digits`, add the current combination to `res`.
  - Get the corresponding letters for the current digit.
  - Iterate through each letter:
    - Append the letter to `path`.
    - Recursively process the next digit.
    - Backtrack by removing the last letter from `path`.
- Return `res` containing all possible letter combinations.

Backtracking explores every possible combination by making a choice, recursively exploring the next level, and undoing the choice before trying another one.

## Complexity

- Time Complexity: **O(4^n × n)**, where `n` is the length of `digits`, since each digit can map to at most 4 letters and joining each combination takes O(n).
- Space Complexity: **O(n)** for the recursion stack and current path, excluding the output space.

## Code

```python
class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        self.phone_map = ["", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"]
        path = []
        res = []
        self.backtrack(digits, 0, path, res)
        return res

    def backtrack(self, digits, digits_index, path, res):
        if len(path) == len(digits):
            res.append("".join(path))
            return

        digit = int(digits[digits_index])
        letters = self.phone_map[digit]

        for letter in letters:
            path.append(letter)
            self.backtrack(digits, digits_index + 1, path, res)
            path.pop()
```
