# 0047. Permutations II

🔗 [LeetCode](https://leetcode.com/problems/permutations-ii/)

## Approach

Use a **Backtracking + Sorting** approach to generate all unique permutations.

- Sort `nums` to group duplicate elements together.
- Initialize `path` to store the current permutation and `res` to store all unique permutations.
- Use a `used` array to track which elements have been selected.
- Backtrack through all elements:
  - If `used[i]` is `True`, skip the element because it has already been used.
  - If the current element is the same as the previous one and the previous one has not been used, skip it to avoid duplicate permutations.
  - Mark the current element as used and add it to `path`.
  - Recursively explore the next position.
  - Backtrack by removing the last element from `path` and resetting `used[i]` to `False`.
- When `len(path) == len(nums)`, append a copy of `path` to `res`.

Sorting and checking `used[i - 1]` ensures that duplicate elements are only selected in a consistent order, avoiding duplicate permutations.

## Complexity

- Time Complexity: **O(n × n!)** in the worst case
- Space Complexity: **O(n)** for the recursion stack, `path`, and `used` array, excluding the output.

## Code

```python
class Solution:
    def permuteUnique(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        path = []
        res = []
        self.backtracking(nums, path, res, [False] * len(nums))
        return res

    def backtracking(self, nums, path, res, used):
        if len(path) == len(nums):
            res.append(path[:])
            return

        for i in range(len(nums)):
            if used[i]:
                continue
            if i > 0 and not used[i - 1] and nums[i] == nums[i - 1]:
                continue

            used[i] = True
            path.append(nums[i])
            self.backtracking(nums, path, res, used)
            path.pop()
            used[i] = False
