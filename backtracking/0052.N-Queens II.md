# 0052. N-Queens II

🔗 [LeetCode](https://leetcode.com/problems/n-queens-ii/)

## Approach

Use a **Backtracking** approach to find all valid ways to place `n` queens on an `n x n` chessboard.

- Initialize the chessboard with `.` and set `count = 0`.
- Start placing queens row by row using backtracking.
- For each row, iterate through all columns:
  - Check whether a queen can be placed at the current position.
  - If valid, place `Q` on the chessboard.
  - Recursively move to the next row.
  - Backtrack by restoring the position to `.`.
- If `row == n`, all queens have been placed successfully, so increment `count`.
- Return `count` as the total number of valid solutions.

To ensure a valid placement, check whether the current column and both upper diagonals contain any queens. Since queens are placed row by row, there is no need to check the current row or lower rows.

## Complexity

- Time Complexity: **O(n! \* n)**, where each row tries available columns and checks whether a queen can be placed.
- Space Complexity: **O(n²)** for the chessboard, excluding the recursion stack.

## Code

```python
class Solution:
    def totalNQueens(self, n: int) -> int:
        chessboard = ['.' * n for _ in range(n)]
        self.count = 0
        self.backtracking(n, 0, chessboard)
        return self.count

    def backtracking(self, n, row, chessboard):
        if row == n:
            self.count += 1
            return

        for col in range(n):
            if self.can_place_queen(n, row, col, chessboard):
                chessboard[row] = chessboard[row][:col] + "Q" + chessboard[row][col+1:]
                self.backtracking(n, row + 1, chessboard)
                chessboard[row] = chessboard[row][:col] + "." + chessboard[row][col+1:]

    def can_place_queen(self, n, row, col, chessboard):
        if row == 0:
            return True

        for i in range(row):
            if chessboard[i][col] == "Q":
                return False

        i, j = row - 1, col - 1
        while i >= 0 and j >= 0:
            if chessboard[i][j] == "Q":
                return False
            i -= 1
            j -= 1

        i, j = row - 1, col + 1
        while i >= 0 and j < n:
            if chessboard[i][j] == "Q":
                return False
            i -= 1
            j += 1

        return True
```
