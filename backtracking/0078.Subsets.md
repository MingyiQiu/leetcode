# 0078. Subsets

🔗 [LeetCode](https://leetcode.com/problems/subsets/)

## Approach

Use a **Backtracking** approach to generate all possible subsets.

- Initialize an empty `path` to store the current subset and `res` to store all subsets.
- Add a copy of `path` to `res` at each recursive call.
- Iterate through the remaining elements starting from `start_index`.
- For each element:
  - Add `nums[i]` to `path`.
  - Recursively call `backtracking` with `i + 1` as the next starting index.
  - Remove the last element from `path` to backtrack and explore other possibilities.

Each recursive call represents a subset, including the empty subset. Using `i + 1` ensures that each element is used at most once and avoids duplicate subsets.

## Complexity

- Time Complexity: **O(n × 2ⁿ)**
- Space Complexity: **O(n)**, excluding the space required to store the results.

## Code

```python
class Solution:
    def subsets(self, nums: list[int]) -> list[list[int]]:
        path = []
        res = []
        self.backtracking(nums, 0, path, res)
        return res

    def backtracking(self, nums, start_index, path, res):
        res.append(path[:])

        for i in range(start_index, len(nums)):
            path.append(nums[i])
            self.backtracking(nums, i + 1, path, res)
            path.pop()
```
