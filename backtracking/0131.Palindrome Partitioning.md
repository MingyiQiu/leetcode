# 0131. Palindrome Partitioning

🔗 [LeetCode](https://leetcode.com/problems/palindrome-partitioning/)

## Approach

Use a **Backtracking** approach to generate all possible palindrome partitions of the string.

- Initialize an empty `path` to store the current partition and `res` to store all valid partitions.
- Start backtracking from index `0`.
- If `start_index` reaches the end of the string, add a copy of `path` to `res`.
- Iterate through the string to explore possible partitions:
  - Extract a substring from `start_index` to `i`.
  - Check if the substring is a palindrome.
  - If it is not a palindrome, skip it.
  - Otherwise, add it to `path` and recursively explore the remaining substring.
  - Backtrack by removing the last substring from `path`.
- Return `res` containing all valid palindrome partitions.

The backtracking process explores every possible partition while only keeping palindrome substrings in the current path.

## Complexity

- Time Complexity: **O(n · 2ⁿ)**, where `n` is the length of the string.
- Space Complexity: **O(n)** for the recursion stack and current path, excluding the output.

## Code

```python
class Solution:
    def partition(self, s: str) -> list[list[str]]:
        path = []
        res = []
        self.backtrack(s, 0, path, res)
        return res

    def backtrack(self, s, start_index, path, res):
        if start_index == len(s):
            res.append(path[:])
            return

        for i in range(start_index, len(s)):
            segment = s[start_index : i + 1]
            if segment != segment[::-1]:
                continue

            path.append(segment)
            self.backtrack(s, i + 1, path, res)
            path.pop()
```
