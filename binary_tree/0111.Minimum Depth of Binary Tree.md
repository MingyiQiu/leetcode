# 0111. Minimum Depth of Binary Tree

🔗 [LeetCode](https://leetcode.com/problems/minimum-depth-of-binary-tree/)

## Approach 1: Breadth-First Search (BFS)

Use a **Breadth-First Search (BFS)** approach to find the minimum depth of the binary tree.

- If the tree is empty, return `0`.
- Initialize a queue with the root node and set `depth = 0`.
- Perform level-order traversal:
  - Increment `depth` before processing each level.
  - Traverse all nodes in the current level.
  - If a node is a leaf node, return the current `depth`.
  - Otherwise, add its non-null children to the queue.
- Since BFS explores the tree level by level, the first leaf node encountered is guaranteed to have the minimum depth.

### Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

### Code

```python
from collections import deque

class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        queue = deque([root])
        depth = 0

        while queue:
            level_size = len(queue)
            depth += 1

            for _ in range(level_size):
                node = queue.popleft()

                if not node.left and not node.right:
                    return depth

                if node.left:
                    queue.append(node.left)

                if node.right:
                    queue.append(node.right)
```

## Approach 2: Recursive Depth-First Search (DFS)

Use **recursion** to compute the minimum depth of the left and right subtrees.

- If the current node is `None`, return `0`.
- Recursively calculate the minimum depth of the left and right subtrees.
- If both subtrees exist, return `min(left, right) + 1`.
- If one subtree is missing, return the depth of the other subtree plus one.
- This special handling is necessary because a missing child does **not** represent a valid path to a leaf node.

### Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(h)**

> `h` is the height of the tree. In the worst case, `h = n`, and in a balanced tree, `h = log n`.

### Code

```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        left_depth = self.minDepth(root.left)
        right_depth = self.minDepth(root.right)

        if left_depth and right_depth:
            return min(left_depth, right_depth) + 1
        elif not right_depth:
            return left_depth + 1
        else:
            return right_depth + 1
```
