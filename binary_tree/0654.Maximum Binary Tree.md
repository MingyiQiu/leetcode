# 0654. Maximum Binary Tree

🔗 [LeetCode](https://leetcode.com/problems/maximum-binary-tree/)

## Approach

Use a **Recursive Divide and Conquer** approach to construct the maximum binary tree.

- If `nums` is empty, return `None`.
- Find the maximum value in `nums` and create a new node as the root.
- Find the index of the maximum value.
- Recursively construct the left subtree using the elements before the maximum value.
- Recursively construct the right subtree using the elements after the maximum value.
- Return the root node.

The maximum value always becomes the root of the current subtree, while the elements on its left and right form the left and right subtrees respectively.

## Complexity

- Time Complexity: **O(n²)** in the worst case
- Space Complexity: **O(n)**

## Code

```python
class Solution:
    def constructMaximumBinaryTree(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None

        max_val = max(nums)
        root = TreeNode(max_val)

        if len(nums) == 1:
            return root

        max_idx = nums.index(max_val)

        root.left = self.constructMaximumBinaryTree(nums[:max_idx])
        root.right = self.constructMaximumBinaryTree(nums[max_idx + 1:])

        return root
```
