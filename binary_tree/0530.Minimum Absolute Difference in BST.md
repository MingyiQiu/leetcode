# 0530. Minimum Absolute Difference in BST

🔗 [LeetCode](https://leetcode.com/problems/minimum-absolute-difference-in-bst/)

## Approach

Use an **In-Order Traversal** approach to find the minimum difference between any two nodes in a binary search tree.

- Initialize `minDiff = inf` to track the minimum difference and `prev = None` to keep track of the previously visited node.
- Recursively traverse the left subtree.
- Compare the current node's value with the previous node's value and update `minDiff` if the difference is smaller.
- Update `prev` to the current node.
- Recursively traverse the right subtree.
- Return `minDiff` as the minimum absolute difference.

For a valid BST, the values visited during an in-order traversal are in **strictly increasing order**, so the minimum difference must occur between two adjacent nodes in the traversal.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(h)**, where `h` is the height of the tree due to the recursion stack.

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def getMinimumDifference(self, root: Optional[TreeNode]) -> int:
        self.minDiff = inf
        self.prev = None
        self.inorder(root)
        return self.minDiff

    def inorder(self, root):
        if not root:
            return

        self.inorder(root.left)

        if self.prev and root.val - self.prev.val < self.minDiff:
            self.minDiff = root.val - self.prev.val
        self.prev = root

        self.inorder(root.right)
