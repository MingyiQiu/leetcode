# 0538. Convert BST to Greater Tree

🔗 [LeetCode](https://leetcode.com/problems/convert-bst-to-greater-tree/)

## Approach

Use a **Reverse In-Order Traversal** approach to convert the BST into a greater tree.

- Initialize `self.curr = 0` to keep track of the sum of all previously visited nodes.
- Traverse the right subtree first, visiting nodes in descending order.
- Add `self.curr` to the current node's value.
- Update `self.curr` to the current node's updated value.
- Recursively traverse the left subtree.
- Return the modified root.

Traversing the BST in reverse in-order ensures that each node is updated with the sum of its original value and all greater values.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(h)**, where `h` is the height of the tree due to the recursion stack.

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        self.curr = 0
        self.traversal(root)
        return root

    def traversal(self, root):
        if not root:
            return

        self.traversal(root.right)
        root.val += self.curr
        self.curr = root.val
        self.traversal(root.left)
```
