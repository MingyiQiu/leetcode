# 0129. Sum Root to Leaf Numbers

🔗 [LeetCode](https://leetcode.com/problems/sum-root-to-leaf-numbers/)

## Approach

Use a **DFS + Backtracking** approach to calculate the sum of all root-to-leaf numbers.

- Initialize `total = 0` to store the sum of all root-to-leaf numbers.
- Initialize `path` with the root value as a string.
- Perform DFS traversal:
  - If the current node is a leaf, convert `path` into a number and add it to `total`.
  - If the left child exists, append its value to `path`, recursively traverse the left subtree, and backtrack by removing the last element.
  - If the right child exists, append its value to `path`, recursively traverse the right subtree, and backtrack by removing the last element.
- Return `total` after traversing all root-to-leaf paths.

Using backtracking allows the same `path` list to be reused for different branches without creating a new list at each recursive call.

## Complexity

- Time Complexity: **O(n \* h)**, where `n` is the number of nodes and `h` is the height of the tree, due to constructing each root-to-leaf number.
- Space Complexity: **O(h)** for the recursion stack and path.

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def sumNumbers(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        self.total = 0
        path = [str(root.val)]
        self.dfs(root, path)

        return self.total

    def dfs(self, root, path):
        if not root.left and not root.right:
            self.total += int("".join(path))
            return

        if root.left:
            path.append(str(root.left.val))
            self.dfs(root.left, path)
            path.pop()

        if root.right:
            path.append(str(root.right.val))
            self.dfs(root.right, path)
            path.pop()
```
