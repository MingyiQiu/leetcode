# 0501. Find Mode in Binary Search Tree

🔗 [LeetCode](https://leetcode.com/problems/find-mode-in-binary-search-tree/)

## Approach

Use an **In-Order Traversal** approach to find the mode(s) in a binary search tree.

- Initialize `freq = 1` to track the frequency of the current value, `maxFreq = 1` to track the maximum frequency, `prev = None` to keep track of the previously visited node, and `res = []` to store the modes.
- Recursively traverse the left subtree.
- Compare the current node's value with the previous node's value:
  - If they are equal, increment `freq`.
  - Otherwise, reset `freq` to `1`.
- Update `prev` to the current node.
- Update the result based on the current frequency:
  - If `freq == maxFreq`, append the current value to `res`.
  - If `freq > maxFreq`, update `maxFreq` and reset `res` to contain only the current value.
- Recursively traverse the right subtree.
- Return `res` as the list of modes.

For a BST, an in-order traversal visits values in **non-decreasing order**, so duplicate values appear consecutively and can be counted efficiently.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(h + k)**, where `h` is the height of the tree and `k` is the number of modes stored in the result.

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def findMode(self, root: Optional[TreeNode]) -> List[int]:
        self.freq = 1
        self.maxFreq = 1
        self.prev = None
        self.res = []
        self.inorder(root)
        return self.res

    def inorder(self, root):
        if not root:
            return

        self.inorder(root.left)

        if self.prev and self.prev.val == root.val:
            self.freq += 1
        else:
            self.freq = 1

        self.prev = root

        if self.freq == self.maxFreq:
            self.res.append(root.val)
        elif self.freq > self.maxFreq:
            self.res = [root.val]
            self.maxFreq = self.freq

        self.inorder(root.right)
```
