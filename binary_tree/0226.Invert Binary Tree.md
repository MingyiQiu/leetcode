# 0226. Invert Binary Tree

🔗 [LeetCode](https://leetcode.com/problems/invert-binary-tree/)

## Approach

Use a **Recursive DFS** approach to invert the binary tree.

- If the current node is `None`, return `None`.
- Recursively invert the left subtree.
- Recursively invert the right subtree.
- Swap the left and right child of the current node.
- Return the current node as the root of the inverted tree.

The recursion traverses every node exactly once, and each node swaps its two children after both subtrees have been processed.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(h)**

> `h` is the height of the tree. In the worst case (a skewed tree), the recursion stack is **O(n)**. For a balanced tree, it is **O(log n)**.

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None

        self.invertTree(root.left)
        self.invertTree(root.right)
        root.left, root.right = root.right, root.left

        return root
```
