# 0513. Find Bottom Left Tree Value

🔗 [LeetCode](https://leetcode.com/problems/find-bottom-left-tree-value/)

## Approach

Use a **Depth-First Search (DFS)** approach to find the leftmost value in the last row of the binary tree.

- Initialize `max_depth` to track the deepest level visited.
- Initialize `result` to store the bottom-left value.
- Start DFS traversal from the root at depth `1`.
- If the current node is a leaf:
  - Check whether its depth is greater than `max_depth`.
  - If so, update `max_depth` and `result`.
- Traverse the left subtree before the right subtree.
- Since the left subtree is always visited first, the first node found at the deepest level is the leftmost value.
- Return `result`.

Traversing the left subtree before the right subtree ensures that when a deeper level is reached, its first leaf is the leftmost node of that level.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(h)**, where `h` is the height of the binary tree due to the recursion stack.

## Code

```python
class Solution:
    def findBottomLeftValue(self, root: Optional[TreeNode]) -> int:
        self.max_depth = 0
        self.result = None

        self.dfs(root, 1)

        return self.result

    def dfs(self, node, depth):
        if not node.left and not node.right:
            if depth > self.max_depth:
                self.max_depth = depth
                self.result = node.val
            return

        if node.left:
            self.dfs(node.left, depth + 1)

        if node.right:
            self.dfs(node.right, depth + 1)
```
