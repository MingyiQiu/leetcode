# 0429. N-ary Tree Level Order Traversal

🔗 [LeetCode](https://leetcode.com/problems/n-ary-tree-level-order-traversal/)

## Approach

Use a **Breadth-First Search (BFS)** approach to traverse the tree level by level.

- Return an empty list if the tree is empty.
- Initialize a queue with the root node.
- While the queue is not empty:
  - Record the number of nodes in the current level.
  - Create a list to store the values of the current level.
  - Process each node in the current level:
    - Remove the front node from the queue.
    - Add all of its children to the queue.
    - Append the node's value to the current level list.
  - Add the completed level list to the result.
- Return the result after all levels have been processed.

Using a queue guarantees that nodes are visited level by level from top to bottom.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
from collections import deque

class Solution:
    def levelOrder(self, root: 'Node') -> List[List[int]]:
        if not root:
            return []

        queue = deque([root])
        result = []

        while queue:
            size = len(queue)
            level = []

            for _ in range(size):
                node = queue.popleft()

                for child in node.children:
                    queue.append(child)

                level.append(node.val)

            result.append(level)

        return result
```
