# 0236. Lowest Common Ancestor of a Binary Tree

🔗 [LeetCode](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/)

## Approach

Use a **Recursive DFS** approach to find the lowest common ancestor (LCA) of two nodes in a binary tree.

- If `root` is `None`, return `None`.
- If `root` is either `p` or `q`, return `root`.
- Recursively search for `p` and `q` in the left and right subtrees.
- Check the results:
  - If both `left` and `right` are not `None`, the current node is the lowest common ancestor.
  - If only `left` is not `None`, return `left`.
  - Otherwise, return `right`.

This approach uses recursion to search both subtrees. If the two target nodes are found in different subtrees, their lowest common ancestor is the current node. Otherwise, the result is propagated upward from the subtree containing a target node.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(h)**, where `h` is the height of the tree due to the recursion stack.

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if not root:
            return None
        elif root.val == p.val or root.val == q.val:
            return root

        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)

        if left and right:
            return root
        elif left:
            return left
        else:
            return right
```
