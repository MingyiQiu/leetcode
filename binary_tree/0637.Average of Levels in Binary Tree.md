# 0637. Average of Levels in Binary Tree

🔗 [LeetCode](https://leetcode.com/problems/average-of-levels-in-binary-tree/)

## Approach

Use **Breadth-First Search (BFS)** with a queue to process the tree level by level.

- If the tree is empty, return an empty list.
- Initialize a queue with the root node.
- While the queue is not empty:
  - Record the number of nodes in the current level.
  - Traverse all nodes in the current level.
  - Accumulate the sum of their values.
  - Add their left and right children to the queue if they exist.
  - Compute the average by dividing the level sum by the number of nodes.
- Return the list of averages.

Since each node is visited exactly once, this approach is efficient and well-suited for level-order traversal.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
from collections import deque

class Solution:
    def averageOfLevels(self, root: Optional[TreeNode]) -> List[float]:
        if not root:
            return []

        result = []
        queue = deque([root])

        while queue:
            level_size = len(queue)
            level_sum = 0

            for _ in range(level_size):
                node = queue.popleft()

                level_sum += node.val

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

            result.append(level_sum / level_size)

        return result
```
