# 0108. Convert Sorted Array to Binary Search Tree

🔗 [LeetCode](https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree/)

## Approach

Use a **Divide and Conquer** approach to construct a height-balanced binary search tree from a sorted array.

- Return `None` if the array is empty.
- Find the middle index `mid` of the array and create a root node using `nums[mid]`.
- Recursively construct the left subtree using the elements before `mid`.
- Recursively construct the right subtree using the elements after `mid`.
- Return the root node.

Choosing the middle element as the root ensures that the left and right subtrees contain approximately equal numbers of elements, producing a height-balanced BST.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**, including the recursion stack and the additional arrays created by slicing.

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None

        mid = len(nums) // 2
        root = TreeNode(nums[mid])

        root.left = self.sortedArrayToBST(nums[:mid])
        root.right = self.sortedArrayToBST(nums[mid + 1:])

        return root
```
