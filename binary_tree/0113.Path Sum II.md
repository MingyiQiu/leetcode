# 0113. Path Sum II

🔗 [LeetCode](https://leetcode.com/problems/path-sum-ii/)

## Approach

Use a **DFS + Backtracking** approach to find all root-to-leaf paths whose sum equals `targetSum`.

- Initialize `path` with the root value and `res` as an empty list.
- Use DFS to traverse the binary tree:
  - Subtract the current node's value from `remaining_sum`.
  - If the current node is a leaf:
    - If `remaining_sum == 0`, append a copy of `path` to `res`.
    - Return to continue exploring other paths.
  - If the left child exists:
    - Append its value to `path`.
    - Recursively traverse the left subtree.
    - Backtrack by removing the last element from `path`.
  - If the right child exists:
    - Append its value to `path`.
    - Recursively traverse the right subtree.
    - Backtrack by removing the last element from `path`.
- Return `res` containing all valid root-to-leaf paths.

Backtracking ensures that each recursive branch maintains its own path without affecting other branches. A copy of `path` is stored in `res` to preserve each valid path.

## Complexity

- Time Complexity: **O(n²)** in the worst case, because copying each valid path can take O(h) time, where `h` is the height of the tree.
- Space Complexity: **O(h)** for the recursion stack and current path, excluding the output list.

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def pathSum(self, root: TreeNode | None, targetSum: int) -> list[list[int]]:
        if not root:
            return []

        path = [root.val]
        res = []
        self.backtracking(root, targetSum - root.val, path, res)
        return res

    def backtracking(self, root, remaining_sum, path, res):
        if not root.left and not root.right:
            if remaining_sum == 0:
                res.append(path[:])
            return

        if root.left:
            path.append(root.left.val)
            self.backtracking(root.left, remaining_sum - root.left.val, path, res)
            path.pop()

        if root.right:
            path.append(root.right.val)
            self.backtracking(root.right, remaining_sum - root.right.val, path, res)
            path.pop()
```
