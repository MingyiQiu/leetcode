# 0235. Lowest Common Ancestor of a Binary Search Tree

🔗 [LeetCode](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-search-tree/)

## Approach

Use a **Recursive BST Traversal** approach to find the lowest common ancestor of two nodes.

- If both `p` and `q` have values greater than `root.val`, recursively search the right subtree.
- If both `p` and `q` have values smaller than `root.val`, recursively search the left subtree.
- Otherwise, the current node is the lowest common ancestor because `p` and `q` are either on different sides of the current node or one of them is the current node.

Since a BST is ordered, we can determine which subtree to search based on the values of `p`, `q`, and `root`, without traversing the entire tree.

## Complexity

- Time Complexity: **O(h)**, where `h` is the height of the tree.
- Space Complexity: **O(h)**, due to the recursion stack.

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if root.val < p.val and root.val < q.val:
            return self.lowestCommonAncestor(root.right, p, q)
        elif root.val > p.val and root.val > q.val:
            return self.lowestCommonAncestor(root.left, p, q)
        else:
            return root
```
