# 0222. Count Complete Tree Nodes

🔗 [LeetCode](https://leetcode.com/problems/count-complete-tree-nodes/)

## Approach

Use a **Complete Binary Tree Optimization** approach.

- If the tree is empty, return `0`.
- Compute the height of the leftmost path and the rightmost path.
- If the two heights are equal, the subtree is a **perfect binary tree**.
  - The number of nodes can be calculated directly using the formula:
    - `(2 << height) - 1` (equivalent to `2^(height + 1) - 1`)
- Otherwise, recursively count the nodes in the left and right subtrees.
- Return the sum of the left subtree, right subtree, and the current root.

This approach avoids traversing every node when a subtree is perfect, making it more efficient than a standard DFS.

## Complexity

- Time Complexity: **O(log² n)**
- Space Complexity: **O(log n)**

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def countNodes(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        leftNode = root.left
        rightNode = root.right
        leftHeight = 0
        rightHeight = 0

        while leftNode:
            leftNode = leftNode.left
            leftHeight += 1

        while rightNode:
            rightNode = rightNode.right
            rightHeight += 1

        if leftHeight == rightHeight:
            return (2 << leftHeight) - 1

        leftCount = self.countNodes(root.left)
        rightCount = self.countNodes(root.right)

        return leftCount + rightCount + 1
```
