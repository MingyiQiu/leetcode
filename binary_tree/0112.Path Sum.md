# 0112. Path Sum

🔗 [LeetCode](https://leetcode.com/problems/path-sum/)

## Approach

Use a **Depth-First Search (DFS)** approach to traverse the binary tree and keep track of the remaining target sum.

- If the root is `None`, return `False`.
- Start the traversal with `targetSum - root.val`.
- For each node:
  - If it is a leaf node, check whether the remaining sum is `0`.
  - If the left child exists, recursively traverse the left subtree with the remaining sum reduced by `root.left.val`.
  - If the right child exists, recursively traverse the right subtree with the remaining sum reduced by `root.right.val`.
- Return `True` if either subtree contains a valid root-to-leaf path.
- If no valid path is found, return `False`.

The remaining sum is updated during the traversal, so there is no need to store the path itself.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(h)**, where `h` is the height of the binary tree due to the recursion stack.

## Code

```python
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        if not root:
            return False

        return self.dfs(root, targetSum - root.val)

    def dfs(self, root, remaining_sum):
        if not root.left and not root.right:
            return remaining_sum == 0

        if root.left:
            if self.dfs(root.left, remaining_sum - root.left.val):
                return True

        if root.right:
            if self.dfs(root.right, remaining_sum - root.right.val):
                return True

        return False
```
