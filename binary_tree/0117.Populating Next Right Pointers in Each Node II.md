# 0117. Populating Next Right Pointers in Each Node II

🔗 [LeetCode](https://leetcode.com/problems/populating-next-right-pointers-in-each-node-ii/)

## Approach

Use a **Breadth-First Search (BFS)** approach to connect nodes level by level.

- Return `None` immediately if the tree is empty.
- Initialize a queue with the root node.
- Process one level at a time:
  - Record the number of nodes in the current level.
  - Use a pointer `prev_node` to keep track of the previous node in the same level.
  - Traverse all nodes in the current level:
    - Pop the front node from the queue.
    - Add its left and right children to the queue if they exist.
    - Connect `prev_node.next` to the current node.
    - Update `prev_node` to the current node.
- Return the original root after all levels have been processed.

Since each level is processed from left to right, every node is connected to its immediate right neighbor.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
from collections import deque

class Solution:
    def connect(self, root: 'Node') -> 'Node':
        if not root:
            return None

        queue = deque([root])

        while queue:
            size = len(queue)
            prev_node = None

            for _ in range(size):
                node = queue.popleft()

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

                if prev_node:
                    prev_node.next = node

                prev_node = node

        return root
```
