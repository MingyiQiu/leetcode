# 0199. Binary Tree Right Side View

🔗 [LeetCode](https://leetcode.com/problems/binary-tree-right-side-view/)

## Approach

Use **Breadth-First Search (Level Order Traversal)** to process the tree level by level.

- Return an empty list if the tree is empty.
- Initialize a queue with the root node.
- Traverse the tree level by level.
- For each level:
  - Record the number of nodes in the current level.
  - Process each node in the level.
  - Add the left child and right child to the queue if they exist.
  - When processing the last node of the current level, add its value to the result.
- Return the result after all levels have been processed.

Since the last node visited at each level is the rightmost visible node, its value represents the right side view of the tree.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
from collections import deque

class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []

        result = []
        queue = deque([root])

        while queue:
            level_size = len(queue)

            for i in range(level_size):
                node = queue.popleft()

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

                if i == level_size - 1:
                    result.append(node.val)

        return result
```
