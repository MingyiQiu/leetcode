# 0669. Trim a Binary Search Tree

🔗 [LeetCode](https://leetcode.com/problems/trim-a-binary-search-tree/)

## Approach

Use a **Recursive BST Traversal** approach to trim the tree so that all node values fall within the range `[low, high]`.

- If `root` is `None`, return `None`.
- If `root.val < low`, discard the current node and its left subtree by recursively trimming the right subtree.
- If `root.val > high`, discard the current node and its right subtree by recursively trimming the left subtree.
- Otherwise, recursively trim the left and right subtrees and update `root.left` and `root.right`.
- Return `root` as the root of the trimmed BST.

Since the tree is a BST, the ordering property allows entire subtrees to be discarded when a node's value falls outside the valid range.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(h)**, where `h` is the height of the tree due to the recursion stack.

## Code

```python
class Solution:
    def trimBST(self, root: Optional[TreeNode], low: int, high: int) -> Optional[TreeNode]:
        if not root:
            return None
        elif root.val < low:
            return self.trimBST(root.right, low, high)
        elif root.val > high:
            return self.trimBST(root.left, low, high)

        root.left = self.trimBST(root.left, low, high)
        root.right = self.trimBST(root.right, low, high)

        return root
```
