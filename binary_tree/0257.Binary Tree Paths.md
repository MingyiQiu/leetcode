# 0257. Binary Tree Paths

🔗 [LeetCode](https://leetcode.com/problems/binary-tree-paths/)

## Approach

Use a **DFS + Backtracking** approach to find all root-to-leaf paths.

- Initialize `path` with the root value and use `paths` to store all valid paths.
- Traverse the tree using DFS.
- If the current node is a leaf node, join the values in `path` with `"->"` and add the path to `paths`.
- If the left child exists:
  - Add its value to `path`.
  - Recursively traverse the left subtree.
  - Remove the last value using `pop()` to backtrack.
- If the right child exists:
  - Add its value to `path`.
  - Recursively traverse the right subtree.
  - Remove the last value using `pop()` to backtrack.
- Return `paths` after traversing the entire tree.

The `path.pop()` step restores the path to its previous state before exploring another branch.

## Complexity

- Time Complexity: **O(n²)** in the worst case due to copying and joining the path for each leaf.
- Space Complexity: **O(n)** for the recursion stack and the current path.

## Code

```python
class Solution:
    def binaryTreePaths(self, root: Optional[TreeNode]) -> List[str]:
        if not root:
            return []

        path = [str(root.val)]
        paths = []

        self.dfs(root, path, paths)

        return paths

    def dfs(self, node, path, paths):
        if not node.left and not node.right:
            paths.append("->".join(path))
            return

        if node.left:
            path.append(str(node.left.val))
            self.dfs(node.left, path, paths)
            path.pop()

        if node.right:
            path.append(str(node.right.val))
            self.dfs(node.right, path, paths)
            path.pop()
```
