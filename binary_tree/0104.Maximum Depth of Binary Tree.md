# 0104. Maximum Depth of Binary Tree

🔗 [LeetCode](https://leetcode.com/problems/maximum-depth-of-binary-tree/)

## Approach

### Approach 1: Breadth-First Search (BFS)

Use a **Level Order Traversal** approach to calculate the maximum depth of the binary tree.

- If the root is `None`, return `0`.
- Initialize a queue with the root node.
- Traverse the tree level by level.
- Count the number of completed levels using `depth`.
- Add child nodes to the queue and continue until all levels are processed.

Each completed level represents an increase in the tree depth.

### Approach 2: Depth-First Search (DFS)

Use a **Recursive DFS** approach to calculate the maximum depth.

- If the current node is `None`, return `0`.
- Recursively calculate the depth of the left subtree.
- Recursively calculate the depth of the right subtree.
- The maximum depth of the current tree is the larger subtree depth plus `1` for the current node.

This approach follows the definition of tree depth directly:  
the depth of a tree equals the maximum depth of its left and right subtrees plus the current node.

## Complexity

### BFS

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

### DFS

- Time Complexity: **O(n)**
- Space Complexity: **O(h)**, where `h` is the height of the tree.

## Code

### BFS

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        queue = deque([root])
        depth = 0

        while queue:
            level_size = len(queue)

            for _ in range(level_size):
                node = queue.popleft()

                if node.left:
                    queue.append(node.left)

                if node.right:
                    queue.append(node.right)

            depth += 1

        return depth
```

### DFS

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        left_depth = self.maxDepth(root.left)
        right_depth = self.maxDepth(root.right)

        return max(left_depth, right_depth) + 1
```
