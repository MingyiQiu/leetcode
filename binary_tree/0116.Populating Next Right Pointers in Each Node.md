# 0116. Populating Next Right Pointers in Each Node

🔗 [LeetCode](https://leetcode.com/problems/populating-next-right-pointers-in-each-node/)

## Approach

Use **Breadth-First Search (BFS)** to connect nodes level by level.

- Return `None` immediately if the tree is empty.
- Initialize a queue with the root node.
- Process one level at a time:
  - Record the number of nodes in the current level.
  - Keep a pointer `prev_node` to track the previous node in the same level.
  - For each node:
    - Remove it from the front of the queue.
    - Add its left and right children to the queue if they exist.
    - Connect `prev_node.next` to the current node.
    - Update `prev_node` to the current node.
- After each level is processed, the last node's `next` pointer remains `None`.
- Return the root node.

This approach processes the tree level by level, ensuring that every node is connected to its adjacent node on the right.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
from collections import deque

class Solution:
    def connect(self, root: 'Optional[Node]') -> 'Optional[Node]':
        if not root:
            return None

        queue = deque([root])

        while queue:
            level_size = len(queue)
            prev_node = None

            for _ in range(level_size):
                node = queue.popleft()

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

                if prev_node:
                    prev_node.next = node
                prev_node = node

        return root
```
