# 0144. Binary Tree Preorder Traversal

🔗 [LeetCode](https://leetcode.com/problems/binary-tree-preorder-traversal/)

## Approach

Use a **Recursive Depth-First Search (DFS)** approach to traverse the binary tree in preorder.

- Create an empty list `result` to store the traversal order.
- Define a recursive helper function `dfs(node)`.
- If the current node is `None`, return.
- Visit the current node by adding its value to `result`.
- Recursively traverse the left subtree.
- Recursively traverse the right subtree.
- Start the traversal from the root node.
- Return `result` after the traversal is complete.

Preorder traversal follows the order: **Root → Left → Right**.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

> The recursion stack can grow up to `O(n)` in the worst case (a completely skewed tree).

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        result = []

        def dfs(node):
            if not node:
                return

            result.append(node.val)
            dfs(node.left)
            dfs(node.right)

        dfs(root)
        return result
```
