# 0001. Two Sum

🔗 [LeetCode](https://leetcode.com/problems/two-sum/)

## Approach

Use a **Hash Map + One Pass** approach to find the two indices efficiently.

- Create a hash map to store each number and its index.
- Traverse the array once using `enumerate`.
- For each number:
  - Calculate its complement as `target - num`.
  - If the complement already exists in the hash map, return the stored index and the current index.
  - Otherwise, store the current number and its index in the hash map.
- Since each number is processed only once, this achieves linear time complexity.

The hash map allows constant-time lookup, making it unnecessary to use nested loops.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        num_to_index = {}

        for i, num in enumerate(nums):
            complement = target - num

            if complement in num_to_index:
                return [num_to_index[complement], i]

            num_to_index[num] = i
```
