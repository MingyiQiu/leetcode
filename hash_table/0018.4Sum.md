# 0018. 4Sum

🔗 [LeetCode](https://leetcode.com/problems/4sum/)

## Approach

Use **Sorting + Two Nested Loops + Two Pointers** to efficiently find all unique quadruplets.

- Sort the array first.
- Iterate through the first number with index `i`.
  - Skip duplicates to avoid repeated quadruplets.
- Iterate through the second number with index `j`.
  - Skip duplicates for the second number as well.
- Use two pointers:
  - `left` starts at `j + 1`
  - `right` starts at the end of the array
- Calculate the sum of the four numbers:
  - If the sum is less than `target`, move `left` forward.
  - If the sum is greater than `target`, move `right` backward.
  - If the sum equals `target`, add the quadruplet to the result and skip duplicate values before moving both pointers.
- Continue until all valid quadruplets have been found.

Sorting allows duplicate removal during traversal, while the two-pointer technique reduces the innermost search from **O(n²)** to **O(n)**.

## Complexity

- Time Complexity: **O(n³)**
- Space Complexity: **O(1)** (excluding the output list)

## Code

```python
class Solution:
    def fourSum(self, nums: List[int], target: int) -> List[List[int]]:
        nums.sort()
        result = []

        for i in range(len(nums) - 3):
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            for j in range(i + 1, len(nums) - 2):
                if j > i + 1 and nums[j] == nums[j - 1]:
                    continue

                left, right = j + 1, len(nums) - 1

                while left < right:
                    total = nums[i] + nums[j] + nums[left] + nums[right]

                    if total < target:
                        left += 1
                    elif total > target:
                        right -= 1
                    else:
                        result.append([nums[i], nums[j], nums[left], nums[right]])

                        while left < right and nums[left] == nums[left + 1]:
                            left += 1
                        while left < right and nums[right] == nums[right - 1]:
                            right -= 1

                        left += 1
                        right -= 1

        return result
```
