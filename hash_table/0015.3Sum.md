# 0015. 3Sum

🔗 [LeetCode](https://leetcode.com/problems/3sum/)

## Approach

Use a **Sorting + Two Pointers** approach to find all unique triplets whose sum is zero.

- Sort the array first.
- Iterate through the array, treating each element as the first number of a triplet.
- Skip duplicate values to avoid repeated triplets.
- For each fixed number, use two pointers:
  - `left` starts at the next index.
  - `right` starts at the end of the array.
- Calculate the sum of the three numbers:
  - If the sum is less than `0`, move `left` to increase the sum.
  - If the sum is greater than `0`, move `right` to decrease the sum.
  - If the sum equals `0`, add the triplet to the result and skip duplicate values on both sides before moving both pointers.
- Continue until all possible triplets have been checked.

Sorting enables the two-pointer technique and makes it easy to skip duplicate values, ensuring that each valid triplet appears only once.

## Complexity

- Time Complexity: **O(n²)**
- Space Complexity: **O(1)** (excluding the output list)

## Code

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        result = []

        for i in range(len(nums) - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            left, right = i + 1, len(nums) - 1

            while left < right:
                current_sum = nums[i] + nums[left] + nums[right]

                if current_sum < 0:
                    left += 1
                elif current_sum > 0:
                    right -= 1
                else:
                    result.append([nums[i], nums[left], nums[right]])

                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1

                    left += 1
                    right -= 1

        return result
```
