# 0349. Intersection of Two Arrays

🔗 [LeetCode](https://leetcode.com/problems/intersection-of-two-arrays/)

## Approach

Use a **Hash Set + Traversal** approach to efficiently find the unique intersection of two arrays.

- Create a set `used` to store all unique elements from `nums1`.
- Traverse `nums1`:
  - If a number is not already in `used`, add it.
- Traverse `nums2`:
  - If a number exists in `used`, it is part of the intersection.
  - Add it to the result list.
  - Remove it from `used` to avoid duplicate results.
- Return the result list.

Using a hash set allows constant-time lookup and removal, ensuring each common element is added only once.

## Complexity

- Time Complexity: **O(n + m)**
- Space Complexity: **O(n)**

## Code

```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        used = set()

        for num in nums1:
            if num not in used:
                used.add(num)

        res = []

        for num in nums2:
            if num in used:
                res.append(num)
                used.remove(num)

        return res
```
