# 0383. Ransom Note

🔗 [LeetCode](https://leetcode.com/problems/ransom-note/)

## Approach

Use a **frequency counting (hash map)** approach.

- First, count the frequency of each character needed in `ransomNote`.
- Then iterate through `magazine` and reduce the required count when a character is found.
- Finally, check if any character still has a positive remaining count.
  - If yes → not enough characters → return `False`
  - Otherwise → return `True`

This ensures every character required by `ransomNote` can be fully constructed from `magazine`.

## Complexity

- Time Complexity: **O(n + m)**
- Space Complexity: **O(1)** (at most 26 letters if lowercase English)

## Code

```python
class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        char_count = {}

        for ch in ransomNote:
            char_count[ch] = char_count.get(ch, 0) + 1

        for ch in magazine:
            if ch in char_count:
                char_count[ch] -= 1

        for cnt in char_count.values():
            if cnt > 0:
                return False

        return True
```
