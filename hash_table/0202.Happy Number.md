# 0202. Happy Number

🔗 [LeetCode](https://leetcode.com/problems/happy-number/)

## Approach

Use a **Hash Set + Simulation** approach to detect whether the process enters a cycle.

- Create a hash set `used` to store previously seen numbers.
- Repeat until `n` becomes `1`:
  - Calculate the sum of the squares of each digit in `n`.
  - If the new sum has already been seen, a cycle exists, so return `False`.
  - Otherwise, add the sum to the hash set and continue with the new value.
- If `n` reaches `1`, return `True`.

A hash set efficiently detects repeated values and determines whether the sequence enters a cycle.

## Complexity

- Time Complexity: **O(log n)** per iteration
- Space Complexity: **O(log n)**

## Code

```python
class Solution:
    def isHappy(self, n: int) -> bool:
        used = set()

        while n != 1:
            squareSum = 0

            for digit in str(n):
                squareSum += int(digit) ** 2

            if squareSum in used:
                return False

            used.add(squareSum)
            n = squareSum

        return True
```
