# 0242. Valid Anagram

🔗 [LeetCode](https://leetcode.com/problems/valid-anagram/)

## Approach

Use a **Frequency Counting** approach to compare the character counts of the two strings.

- Create an array `res` of size `26` to store the frequency of each lowercase letter.
- Traverse string `s` and increment the corresponding count for each character.
- Traverse string `t` and decrement the corresponding count for each character.
- Traverse the frequency array:
  - If any value is not `0`, the two strings have different character frequencies, so return `False`.
- If all frequencies are `0`, return `True`.

This approach counts the occurrences of each letter in both strings and checks whether the final frequencies are balanced.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        res = [0] * 26

        for char in s:
            res[ord(char) - ord('a')] += 1

        for char in t:
            res[ord(char) - ord('a')] -= 1

        for freq in res:
            if freq != 0:
                return False

        return True
```
