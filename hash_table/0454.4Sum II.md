# 0454. 4Sum II

🔗 [LeetCode](https://leetcode.com/problems/4sum-ii/)

## Approach

Use a **Hash Map + Two-Pass** approach to reduce the time complexity from **O(n⁴)** to **O(n²)**.

- Create a hash map to store the frequency of every possible sum of elements from `nums1` and `nums2`.
- Traverse every pair from `nums3` and `nums4`.
- For each pair, calculate the value needed to make the total sum equal to `0`.
- If the required value exists in the hash map, add its frequency to the answer.
- Return the total count.

By precomputing the sums of the first two arrays, each lookup for the remaining two arrays can be done in **O(1)** time.

## Complexity

- Time Complexity: **O(n²)**
- Space Complexity: **O(n²)**

## Code

```python
class Solution:
    def fourSumCount(
        self,
        nums1: List[int],
        nums2: List[int],
        nums3: List[int],
        nums4: List[int],
    ) -> int:
        sum_count = {}

        for a in nums1:
            for b in nums2:
                sum_count[a + b] = sum_count.get(a + b, 0) + 1

        count = 0

        for c in nums3:
            for d in nums4:
                complement = -(c + d)
                if complement in sum_count:
                    count += sum_count[complement]

        return count
```
