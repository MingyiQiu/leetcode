# 1005. Maximize Sum Of Array After K Negations

🔗 [LeetCode](https://leetcode.com/problems/maximize-sum-of-array-after-k-negations/)

## Approach

Use a **Greedy + Sorting** approach to maximize the sum of the array after performing `k` negations.

- Sort the array by the absolute values of elements in descending order.
- Traverse the array:
  - If `k > 0` and the current number is negative, flip it to positive.
  - Decrement `k` after each negation.
- If `k` is still odd, flip the element with the smallest absolute value (`nums[-1]`).
- Return the sum of the array.

Flipping numbers with larger absolute values first maximizes the sum. If there are remaining operations, flipping the number with the smallest absolute value minimizes the impact.

## Complexity

- Time Complexity: **O(n log n)**
- Space Complexity: **O(1)**, ignoring the sorting implementation's internal space.

## Code

```python
class Solution:
    def largestSumAfterKNegations(self, nums: List[int], k: int) -> int:
        nums.sort(key=lambda x: -abs(x))

        for i in range(len(nums)):
            if k > 0 and nums[i] < 0:
                nums[i] *= -1
                k -= 1

        if k % 2 == 1:
            nums[-1] *= -1

        return sum(nums)
```
