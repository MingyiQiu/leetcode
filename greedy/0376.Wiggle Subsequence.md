# 0376. Wiggle Subsequence

🔗 [LeetCode](https://leetcode.com/problems/wiggle-subsequence/)

## Approach

Use a **Greedy** approach to find the longest wiggle subsequence.

- Initialize `prev_diff = 0` to track the previous non-zero difference.
- Initialize `count = 1` because a single element is a valid wiggle subsequence.
- Traverse the array starting from the second element.
- Calculate the difference between the current element and the previous element.
- If the previous difference and current difference have opposite signs, or the previous difference is zero and the current difference is non-zero:
  - Increment `count`.
  - Update `prev_diff` to `curr_diff`.
- Return `count` as the maximum length of the wiggle subsequence.

By only counting direction changes, this greedy approach skips unnecessary elements and keeps the longest wiggle subsequence.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def wiggleMaxLength(self, nums: list[int]) -> int:
        prev_diff = 0
        count = 1

        for i in range(1, len(nums)):
            curr_diff = nums[i] - nums[i - 1]

            if (prev_diff >= 0 and curr_diff < 0) or (prev_diff <= 0 and curr_diff > 0):
                count += 1
                prev_diff = curr_diff

        return count
```
