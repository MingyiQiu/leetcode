# 0045. Jump Game II

🔗 [LeetCode](https://leetcode.com/problems/jump-game-ii/)

## Approach

Use a **Greedy** approach to find the minimum number of jumps needed to reach the last index.

- Initialize `farthest` to track the farthest reachable index, `currentEnd` to mark the current jump boundary, and `jumps` to count the number of jumps.
- Traverse the array up to the second-to-last index.
- Update `farthest` to the maximum index reachable from the current position.
- When `i` reaches `currentEnd`, the current jump range is exhausted:
  - Update `currentEnd` to `farthest`.
  - Increment `jumps` by one.
- Return `jumps` as the minimum number of jumps needed to reach the last index.

By expanding the reachable range at each boundary, each jump covers the farthest possible distance within the current range.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def jump(self, nums: list[int]) -> int:
        farthest, currentEnd = 0, 0
        jumps = 0

        for i in range(len(nums) - 1):
            farthest = max(farthest, nums[i] + i)

            if i == currentEnd:
                currentEnd = farthest
                jumps += 1

        return jumps
```
