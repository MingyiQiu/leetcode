# 0055. Jump Game

🔗 [LeetCode](https://leetcode.com/problems/jump-game/)

## Approach

Use a **Greedy** approach to keep track of the maximum reachable index.

- Initialize `max_reach = 0` to track the farthest index that can be reached.
- Traverse the array while `index <= max_reach`.
- Update `max_reach` to the maximum of its current value and `index + nums[index]`.
- If `max_reach` reaches or exceeds the last index, return `True`.
- Otherwise, move to the next index.
- Return `False` if the current index exceeds `max_reach`.

By continuously updating the farthest reachable index, we can determine whether the last index is reachable without actually making any jumps.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def canJump(self, nums: list[int]) -> bool:
        index, max_reach = 0, 0

        while index <= max_reach:
            max_reach = max(max_reach, index + nums[index])

            if max_reach >= len(nums) - 1:
                return True

            index += 1

        return False
```
