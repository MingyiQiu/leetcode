# 0135. Candy

🔗 [LeetCode](https://leetcode.com/problems/candy/)

## Approach

Use a **Two Pass Greedy** approach to calculate the minimum number of candies each child should receive.

- Initialize two arrays `candy_l` and `candy_r` with `1` for every child.
- Traverse from left to right:
  - If the current child's rating is higher than the previous child's rating, assign one more candy than the previous child.
- Traverse from right to left:
  - If the previous child's rating is higher than the current child's rating, assign one more candy than the current child.
- Calculate the total number of candies by adding the maximum value between `candy_l[i]` and `candy_r[i]` for each child.
- Return the total number of candies.

Using two passes ensures that both left and right neighbor conditions are satisfied while giving each child the minimum number of candies.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
class Solution:
    def candy(self, ratings: List[int]) -> int:
        candy_l = [1] * len(ratings)
        candy_r = [1] * len(ratings)

        for i in range(1, len(ratings)):
            if ratings[i] > ratings[i - 1]:
                candy_l[i] = candy_l[i - 1] + 1

        for i in range(len(ratings) - 1, 0, -1):
            if ratings[i - 1] > ratings[i]:
                candy_r[i - 1] = candy_r[i] + 1

        candies = 0
        for i in range(len(ratings)):
            candies += max(candy_l[i], candy_r[i])

        return candies
```
