# 0053. Maximum Subarray

🔗 [LeetCode](https://leetcode.com/problems/maximum-subarray/)

## Approach

Use a **Greedy** approach to find the maximum sum of a contiguous subarray.

- Initialize `curr` and `total` to `-inf` to handle arrays containing only negative numbers.
- Traverse each number in `nums`:
  - If `curr` is negative, reset `curr` to the current number.
  - Otherwise, add the current number to `curr`.
  - Update `total` with the maximum value between `total` and `curr`.
- Return `total` as the maximum subarray sum.

By resetting `curr` whenever it becomes negative, the algorithm avoids carrying a negative sum that would reduce the sum of a future subarray.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        curr = -inf
        total = -inf

        for num in nums:
            if curr < 0:
                curr = num
            else:
                curr += num

            total = max(total, curr)

        return total
```
