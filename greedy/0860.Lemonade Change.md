# 0860. Lemonade Change

🔗 [LeetCode](https://leetcode.com/problems/lemonade-change/)

## Approach

Use a **Greedy** approach to provide change while keeping track of available $5 and $10 bills.

- Initialize `five` and `ten` to track the number of $5 and $10 bills.
- Traverse each bill in `bills`:
  - If the bill is $5, increment `five`.
  - If the bill is $10:
    - Use one $5 bill as change.
    - If no $5 bill is available, return `False`.
  - If the bill is $20:
    - Prefer using one $10 bill and one $5 bill as change.
    - Otherwise, use three $5 bills.
    - If neither option is available, return `False`.
- Return `True` if all customers receive the correct change.

Prioritizing the use of a $10 bill and a $5 bill preserves more $5 bills for future transactions.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def lemonadeChange(self, bills: List[int]) -> bool:
        five, ten = 0, 0

        for bill in bills:
            if bill == 5:
                five += 1
            elif bill == 10:
                if five >= 1:
                    five -= 1
                    ten += 1
                else:
                    return False
            else:
                if five >= 1 and ten >= 1:
                    five -= 1
                    ten -= 1
                elif five >= 3:
                    five -= 3
                else:
                    return False

        return True
```
