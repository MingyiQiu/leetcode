# 0134. Gas Station

🔗 [LeetCode](https://leetcode.com/problems/gas-station/)

## Approach

Use a **Greedy** approach to find the starting gas station that allows completing the circuit.

- Initialize `total = 0` to track the overall gas surplus.
- Initialize `curr = 0` to track the current gas surplus from the starting station.
- Initialize `start = 0` as the candidate starting index.
- Traverse all gas stations:
  - Calculate the gas surplus by adding `gas[i] - cost[i]` to both `curr` and `total`.
  - If `curr < 0`, the current starting point cannot reach the next station:
    - Reset `curr = 0`.
    - Update `start = i + 1` to try the next station as the starting point.
- Return `start` if `total >= 0`; otherwise, return `-1`.

If the total gas is sufficient to cover the total cost, a valid starting station must exist. Resetting the current surplus helps eliminate impossible starting positions.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def canCompleteCircuit(self, gas: list[int], cost: list[int]) -> int:
        total, curr = 0, 0
        start = 0

        for i in range(len(gas)):
            curr += gas[i] - cost[i]

            if curr < 0:
                curr = 0
                start = i + 1

            total += gas[i] - cost[i]

        return start if total >= 0 else -1
```
