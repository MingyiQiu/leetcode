# 0122. Best Time to Buy and Sell Stock II

🔗 [LeetCode](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/)

## Approach

Use a **Greedy** approach to maximize profit by adding every positive price difference between consecutive days.

- Initialize `total = 0` to track the maximum profit.
- Traverse the prices starting from the second day.
- Calculate the price difference between the current day and the previous day.
- If the price difference is positive, add it to `total`.
- Return `total` as the maximum profit.

By adding all positive price differences, the solution captures every profitable upward movement in the stock price.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        total = 0

        for i in range(1, len(prices)):
            profit = prices[i] - prices[i - 1]
            if profit > 0:
                total += profit

        return total
```
