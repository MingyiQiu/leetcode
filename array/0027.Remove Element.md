# 27. Remove Element

## Approach

Use the **Two Pointers** technique to overwrite the elements that are not equal to `val`.

- Initialize a pointer `slow` to indicate the position where the next valid element should be placed.
- Iterate through the array with pointer `fast`.
- If `nums[fast]` is not equal to `val`, copy it to `nums[slow]` and move `slow` forward.
- If `nums[fast]` equals `val`, skip it.
- After traversal, `slow` represents the number of remaining elements.

The first `slow` elements of `nums` contain all the elements that are not equal to `val`.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        slow = 0

        for fast in range(len(nums)):
            if nums[fast] != val:
                nums[slow] = nums[fast]
                slow += 1

        return slow
```
