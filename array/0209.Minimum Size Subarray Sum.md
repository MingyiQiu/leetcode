# 209. Minimum Size Subarray Sum

🔗 [LeetCode](https://leetcode.com/problems/minimum-size-subarray-sum/)

## Approach

Use the **Sliding Window** technique.

Maintain a window `[left, right]` and keep track of the current sum of elements inside the window.

- Expand the window by moving `right` and adding `nums[right]` to the current sum.
- Whenever the window sum becomes greater than or equal to `target`, try to shrink the window from the left.
- While shrinking:
  - Update the minimum window length.
  - Remove `nums[left]` from the sum.
  - Move `left` forward.
- Continue until all elements have been processed.

Since all numbers in `nums` are positive, shrinking the window always decreases the sum, making the sliding window approach valid.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        windowLength = inf
        windowSum = 0
        left = 0

        for right in range(len(nums)):
            windowSum += nums[right]

            while windowSum >= target:
                windowLength = min(windowLength, right - left + 1)
                windowSum -= nums[left]
                left += 1

        return windowLength if windowLength != inf else 0
```
