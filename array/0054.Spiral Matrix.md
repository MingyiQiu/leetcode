# 0054. Spiral Matrix

🔗 [LeetCode](https://leetcode.com/problems/spiral-matrix/)

## Approach

Use the **Boundary Simulation (Four Pointers)** technique to traverse the matrix layer by layer in spiral order.

- Define four boundaries:
  - `top` → first unvisited row from the top
  - `bottom` → first unvisited row from the bottom
  - `left` → first unvisited column from the left
  - `right` → first unvisited column from the right

Then repeatedly traverse the matrix in four steps:

- Traverse from `left → right` along the top row, then move `top` down.
- Traverse from `top → bottom` along the right column, then move `right` left.
- If rows remain, traverse from `right → left` along the bottom row, then move `bottom` up.
- If columns remain, traverse from `bottom → top` along the left column, then move `left` right.

Continue until all boundaries overlap.

This approach ensures each element is visited exactly once.

## Complexity

- Time Complexity: **O(m × n)**
- Space Complexity: **O(1)** (excluding output list)

## Code

```python
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        res = []
        top, bottom = 0, len(matrix) - 1
        left, right = 0, len(matrix[0]) - 1

        while top <= bottom and left <= right:
            # left -> right
            for col in range(left, right + 1):
                res.append(matrix[top][col])
            top += 1

            # top -> bottom
            for row in range(top, bottom + 1):
                res.append(matrix[row][right])
            right -= 1

            # right -> left
            if top <= bottom:
                for col in range(right, left - 1, -1):
                    res.append(matrix[bottom][col])
                bottom -= 1

            # bottom -> top
            if left <= right:
                for row in range(bottom, top - 1, -1):
                    res.append(matrix[row][left])
                left += 1

        return res
```
