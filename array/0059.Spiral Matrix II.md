# 0059. Spiral Matrix II

🔗 [LeetCode](https://leetcode.com/problems/spiral-matrix-ii/)

## Approach

Fill the matrix layer by layer in spiral order using boundary simulation.

Each layer consists of four directions:

· Left → Right (top row)  
· Top → Bottom (right column)  
· Right → Left (bottom row)  
· Bottom → Top (left column)

Maintain:

· start: current layer starting index  
· offset: shrinking boundary indicator  
· count: value to fill into the matrix

After finishing one layer, move inward by increasing start.

### Special Case

If n is odd, the center cell is filled with the last remaining value.

---

## Complexity

- Time Complexity: **O(n²)**
- Space Complexity: **O(n²)**

## Code

```python
class Solution:
    def generateMatrix(self, n: int) -> List[List[int]]:
        res = [[0] * n for _ in range(n)]

        offset = 1
        count = 0
        start = 0

        for offset in range(1, n // 2 + 1):
            for col in range(start, n - offset):
                count += 1
                res[start][col] = count

            for row in range(start, n - offset):
                count += 1
                res[row][n - offset] = count

            for col in range(n - offset, start, -1):
                count += 1
                res[n - offset][col] = count

            for row in range(n - offset, start, -1):
                count += 1
                res[row][start] = count

            start += 1

        if n % 2 == 1:
            count += 1
            res[start][start] = count

        return res
```
