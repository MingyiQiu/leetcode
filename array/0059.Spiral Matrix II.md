# 59. Spiral Matrix II

🔗 [LeetCode](https://leetcode.com/problems/spiral-matrix-ii/)

## Approach

We simulate filling the matrix in **spiral order** layer by layer.

Each layer is filled in 4 steps:

- Left → Right (top row)
- Top → Bottom (right column)
- Right → Left (bottom row)
- Bottom → Top (left column)

We maintain:

- `start`: starting index of the current layer
- `offset`: shrinking boundary for each loop
- `count`: value to fill into the matrix

After finishing one layer, we move inward by increasing `start`.

### Special Case

If `n` is odd, the center cell is filled separately at the end.

---

## Complexity

- Time Complexity: **O(n²)**
- Space Complexity: **O(n²)**

## Code

```python
class Solution:
    def generateMatrix(self, n: int) -> List[List[int]]:
        res = [[0] * n for _ in range(n)]

        offset = 1
        count = 0
        start = 0

        for offset in range(1, n // 2 + 1):
            for col in range(start, n - offset):
                count += 1
                res[start][col] = count

            for row in range(start, n - offset):
                count += 1
                res[row][n - offset] = count

            for col in range(n - offset, start, -1):
                count += 1
                res[n - offset][col] = count

            for row in range(n - offset, start, -1):
                count += 1
                res[row][start] = count

            start += 1

        if n % 2 == 1:
            count += 1
            res[start][start] = count

        return res
```
