# 977. Squares of a Sorted Array

🔗 [LeetCode](https://leetcode.com/problems/squares-of-a-sorted-array/)

## Approach

Use the **Two Pointers** technique to find the largest square at each step.

- Initialize two pointers:
  - `left` at the beginning of the array.
  - `right` at the end of the array.
- Compare the absolute values of `nums[left]` and `nums[right]`.
- The larger absolute value will produce the larger square.
- Append that square to the result array and move the corresponding pointer inward.
- Continue until all elements have been processed.
- Since the result is constructed from largest to smallest squares, reverse the array before returning.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        res = []
        left, right = 0, len(nums) - 1

        while left <= right:
            if abs(nums[left]) < abs(nums[right]):
                res.append(nums[right] ** 2)
                right -= 1
            else:
                res.append(nums[left] ** 2)
                left += 1

        return res[::-1]
```
