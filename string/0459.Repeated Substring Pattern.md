# 0459. Repeated Substring Pattern

🔗 [LeetCode](https://leetcode.com/problems/repeated-substring-pattern/)

## Approach

Build the candidate pattern one character at a time and check whether repeating it can reconstruct the original string.

- Initialize an empty string `pattern`.
- Iterate through the first half of the string.
- Append the current character to `pattern`.
- Repeat `pattern` `len(s) // len(pattern)` times.
- If the repeated string is equal to `s`, return `True`.
- If no valid pattern is found after checking all candidates, return `False`.

A valid repeating substring cannot be longer than half of the original string, so only the first half needs to be checked.

## Complexity

- Time Complexity: **O(n²)**
- Space Complexity: **O(n)**

## Code

```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        pattern = ""

        for end in range(len(s) // 2):
            pattern += s[end]

            if len(s) // len(pattern) * pattern == s:
                return True

        return False
```
