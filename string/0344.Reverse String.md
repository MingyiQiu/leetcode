# 0344. Reverse String

🔗 [LeetCode](https://leetcode.com/problems/reverse-string/)

## Approach

Use a **Two Pointers** approach to reverse the string in-place.

- Initialize two pointers:
  - `left` at the beginning of the list.
  - `right` at the end of the list.
- While `left` is less than `right`:
  - Swap the characters at `left` and `right`.
  - Move `left` one step to the right.
  - Move `right` one step to the left.
- Continue until the two pointers meet or cross.

This approach reverses the string in-place without using any extra space.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(1)**

## Code

```python
class Solution:
    def reverseString(self, s: List[str]) -> None:
        """
        Do not return anything, modify s in-place instead.
        """
        left, right = 0, len(s) - 1

        while left < right:
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1
```
