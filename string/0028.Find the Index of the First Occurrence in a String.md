# 0028. Find the Index of the First Occurrence in a String

🔗 [LeetCode](https://leetcode.com/problems/find-the-index-of-the-first-occurrence-in-a-string/)

## Approach

Use a **Sliding Window** approach to compare each substring of `haystack` with `needle`.

- Traverse every possible starting index in `haystack`.
- At each index, extract a substring with the same length as `needle`.
- Compare the substring with `needle`.
- If they are equal, return the current index.
- If no match is found after checking all positions, return `-1`.

Python slicing automatically handles cases where the end index exceeds the string length, so no extra boundary checks are needed.

## Complexity

- Time Complexity: **O((n - m + 1) × m)**
  - `n` = length of `haystack`
  - `m` = length of `needle`
- Space Complexity: **O(m)**
  - Each slice creates a new substring of length `m`.

## Code

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        needle_len = len(needle)

        for start in range(len(haystack)):
            if haystack[start:start + needle_len] == needle:
                return start

        return -1
```
