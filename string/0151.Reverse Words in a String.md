# 0151. Reverse Words in a String

🔗 [LeetCode](https://leetcode.com/problems/reverse-words-in-a-string/)

## Approach

Use **Split + Reverse + Join** to reverse the order of words.

- Split the string into a list of words using `split()`.
  - `split()` automatically removes leading, trailing, and extra spaces.
- Reverse the list of words using slicing (`[::-1]`).
- Join the reversed words with a single space using `" ".join()`.

This approach is concise and leverages Python's built-in string methods to handle whitespace efficiently.

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**

## Code

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        return " ".join(s.split()[::-1])
```
